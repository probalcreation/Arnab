# ডায়মন্ড — কম্পিউটার এন্ড অনলাইন সার্ভিস

এই ফোল্ডারে একটি responsive one-page online service shop website আছে।

## ফাইল
- `index.html` — মূল ওয়েবসাইট
- `styles.css` — ডিজাইন ও responsive CSS
- `script.js` — mobile menu, scroll-to-top ও current year
- `banner.jpg` — আপনার দেওয়া দোকানের ব্যানার

## ব্যবহার
সব ফাইল একই ফোল্ডারে রেখে `index.html` ডাবল-ক্লিক করে browser-এ খুলুন।

## অনলাইনে প্রকাশ
Netlify, GitHub Pages, Vercel বা যেকোনো সাধারণ hosting-এ এই চারটি ফাইল upload করলেই সাইটটি চালু হবে।

## যেগুলো সহজে পরিবর্তন করা যাবে
`index.html`-এর মধ্যে দোকানের নাম, ফোন, WhatsApp, ই-মেইল, ঠিকানা ও সেবার তালিকা পরিবর্তন করতে পারবেন।
